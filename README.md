# btc-dashboard-data

Ежедневные рыночные данные для дашборда «BTC: вероятностная панель».

GitHub Actions раз в день запускает `fetch.py` и коммитит в папку `data/`:

| Файл | Что внутри | Источник |
|---|---|---|
| `data/btc_daily.csv` | дневная цена BTC, MVRV и реализованная цена с 2010 года | Coin Metrics community API |
| `data/macro_daily.csv` | доходность UST 10Y, реальная доходность TIPS 10Y, широкий индекс доллара с 2010 года | FRED (DGS10, DFII10, DTWEXBGS) |
| `data/latest.json` | последние значения для дашборда: цена, реализованная цена, MVRV, 200D, 200W, ATH, индекс страха и жадности, UST 10Y, реальная 10Y, DXY, funding — у каждого дата и источник | всё перечисленное, плюс alternative.me, Yahoo Finance, OKX/Deribit |

Цена, MVRV, средние и ATH считаются из того же ряда Coin Metrics, на котором обучена модель, поэтому признаки на дашборде совпадают с обучением.

Потоки ETF, себестоимость краткосрочных и долгосрочных держателей и вероятности по FedWatch бесплатного API не имеют. Их по-прежнему раз в неделю собирает запланированная задача Claude.

## Запуск

- Автоматически: ежедневно в 05:17 UTC.
- Вручную: вкладка **Actions** → **Update market data** → **Run workflow**.
- Локально: `python fetch.py` (нужен только Python 3.10+, без внешних пакетов).

Если какой-то источник недоступен, его значение записывается как `null`, а причина — в поле `errors` файла `latest.json`. Если данные Coin Metrics старше трёх дней, это тоже попадает в `errors`, и еженедельная задача берёт цену из других источников. Без Coin Metrics запуск падает, чтобы не записать пустые данные.

Репозиторий должен быть публичным: еженедельная задача Claude читает `latest.json` по адресу `https://raw.githubusercontent.com/<владелец>/btc-dashboard-data/main/data/latest.json`. Здесь только публичные рыночные данные и код, личных данных нет.

## Модель

`model/model2.py` обучает вероятностную модель панели на данных из `data/`: логистическая регрессия на недельных точках с 2014 года, проверка вне выборки по годам с разрывом на длину горизонта, бутстрэп по годам. Переобучение (раз в квартал):

```
pip install pandas numpy scikit-learn
python model/model2.py data/btc_daily.csv data/macro_daily.csv out            # сравнение вариантов
python model/model2.py data/btc_daily.csv data/macro_daily.csv out --final base 0.1
```

`model/score.py` считает вероятности для одного снимка: `python model/score.py ДАТА ЦЕНА РЕАЛИЗОВАННАЯ 200D 200W ATH`.

Проверка 25.11.2026: варианты с макро-признаками (изменение реальной доходности 10Y и широкого индекса доллара за 90 и 180 дней, уровень реальной доходности) не улучшили прогнозы вне выборки 2018–2026 по всем трём целям, поэтому основная модель обходится без них.
